Here is a Python function to sort a list of numbers using bubble sort:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using bubble sort.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: A sorted list of numbers.
    """
    n = len(numbers)
    for i in range(n):
        # Create a copy of the list to avoid modifying the original list
        numbers_copy = numbers[:]

        # Traverse the list from the first element to the (n-i-1)th element
        for j in range(n - i - 1):
            # If the current element is greater than the next element, swap them
            if numbers_copy[j] > numbers_copy[j + 1]:
                # Swap the elements
                numbers_copy[j], numbers_copy[j + 1] = numbers_copy[j + 1], numbers_copy[j]

        # Update the original list with the sorted copy
        numbers[:] = numbers_copy

    return numbers

# Example usage:
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print("Sorted numbers:", sorted_numbers
