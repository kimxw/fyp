Here is a Python function that implements bubble sort to sort a list of numbers in ascending order:

```python
def bubble_sort(lst):
    n = len(lst)

    for i in range(n):

        # Last i elements are already sorted
        for j in range(0, n-i-1):

            # Traverse the list from 0 to n-i-1
            # Swap if the element found is greater than the next element
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]

    return lst

# Test the function
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print(sorted_numbers)
```

In this function, `bubble_sort` takes a list of numbers as input and sorts it in ascending order. The outer loop runs from 0 to `n-1`, where `n` is the number of elements in the list. For each iteration of the outer loop, the inner loop runs from 0 to `n-i-1`, where `i` is the current iteration of the outer loop.
