## Bubble Sort Function in Python

Here is a Python implementation of the bubble sort algorithm:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using the bubble sort algorithm.

    Args:
        numbers (list): The list of numbers to sort.

    Returns:
        list: The sorted list of numbers.
    """
    # Create a copy of the original list to avoid modifying it in place
    numbers_copy = numbers.copy()

    # Get the length of the list
    n = len(numbers_copy)

    # Repeat the process until no more swaps are needed
    for i in range(n-1):
        # Initialize a flag to track if any swaps were made in the current pass
        swapped = False

        # Iterate through the list from the first element to the second last element
        for j in range(n-i-1):
            # If the current element is greater than the next element, swap them
            if numbers_copy[j] > numbers_copy[j+1]:
                # Swap the elements
                numbers_copy[j], numbers_copy[j+1] = numbers_copy[j+1], numbers_copy[j]
                # Set the flag to True to indicate that a swap was made
                swapped = True
