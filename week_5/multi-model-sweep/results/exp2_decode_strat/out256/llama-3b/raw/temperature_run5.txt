### Bubble Sort Function in Python

Here's an implementation of the bubble sort algorithm in Python:

```python
def bubble_sort(lst):
    """
    Sorts a list of numbers using the bubble sort algorithm.

    Args:
        lst (list): The list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """
    # Create a copy of the input list to avoid modifying it in-place
    lst_copy = lst.copy()

    # Get the length of the list
    n = len(lst_copy)

    # Repeat the process until no more swaps are needed
    for i in range(n):
        # Initialize a flag to track if any swaps were made in the current pass
        swapped = False

        # Iterate through the list, comparing each pair of adjacent elements
        for j in range(n - 1):
            # If the current element is greater than the next element, swap them
            if lst_copy[j] > lst_copy[j + 1]:
                # Swap the elements
                lst_copy[j], lst_copy[j + 1] = lst_copy[j + 1], lst_copy[j]
                # Set the flag to True to indicate that a swap was made
                swapped = True
