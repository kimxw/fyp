```python
def bubble_sort(numbers):
    # Get the length of the list
    n = len(numbers)
    
    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n-i-1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater than the next element
            if numbers[j] > numbers[j+1]:
                numbers[j], numbers[j+1] = numbers[j+1], numbers[j]

# Example usage:
numbers = [64, 34, 25, 12, 22, 11, 90]
bubble_sort(numbers)
print("Sorted array is:", numbers)
```

In this solution, we define a function `bubble_sort` that takes a list of numbers as input. The function first calculates the length of the list. It then uses two nested loops to iterate through the list. The outer loop runs from the first element to the second-to-last element. The inner loop runs from the first element to the last element minus the current iteration number (to avoid unnecessary comparisons). During each iteration, if the current element is greater than the next element, the elements are swapped. This process is repeated until the list is sorted. Finally, the sorted list is printed.
