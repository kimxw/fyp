**Bubble Sort Implementation**
=====================================

Here's a Python function that implements bubble sort, a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using bubble sort.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """
    n = len(numbers)

    for i in range(n):
        # Create a flag that will allow the function to terminate early if there's nothing left to sort
        swapped = False

        # Start looking at each item of the list one by one, comparing it with its adjacent value
        for j in range(n - 1):
            # If we find an element that is greater than its adjacent element, then swap them
            if numbers[j] > numbers[j + 1]:
                # Swap values
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
                # Set the flag to True so we'll loop again after this iteration
                swapped = True

        # If we didn't swap any elements in inner loop, that means the list is sorted
        if not swapped:
            break

    return numbers

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
print("Original list:", numbers)
sorted_numbers = bubble_sort(numbers)
print("Sorted list:", sorted_numbers)
```

This implementation of bubble sort has a time complexity of O(n^2), making it less efficient than other sorting algorithms like quicksort or mergesort for large datasets. However, it can be useful for educational purposes or small datasets.
