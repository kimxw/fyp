Certainly! Below is a function implemented in Python that sorts a list of numbers using the bubble sort algorithm. The function includes an early-exit optimization to stop the algorithm if a full pass completes with no swaps, which indicates that the list is already sorted.

```python
def bubble_sort(arr):
    n = len(arr)
    # Traverse through all array elements
    for i in range(n):
        # Last i elements are already in place
        for j in range(0, n-i-1):
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater than the next element
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# Example usage:
unsorted_list = [64, 34, 25, 12, 22, 11, 90]
sorted_list = bubble_sort(unsorted_list)
print("Sorted list:", sorted_list)
```

### Explanation:
1. **Outer Loop (`for i in range(n)`)**: This loop runs `n` times, where `n` is the number of elements in the list
