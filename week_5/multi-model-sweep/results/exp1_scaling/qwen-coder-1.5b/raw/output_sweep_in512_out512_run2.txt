```python
def bubble_sort(numbers):
    n = len(numbers)
    
    # Traverse through all array elements
    for i in range(n):
        # Last i elements are already in place
        for j in range(0, n-i-1):
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater than the next element
            if numbers[j] > numbers[j+1]:
                numbers[j], numbers[j+1] = numbers[j+1], numbers[j]
    
    return numbers

# Example usage:
unsorted_list = [64, 34, 25, 12, 22, 11, 90]
sorted_list = bubble_sort(unsorted_list)
print("Sorted list:", sorted_list)
```

### Explanation:
1. **Outer Loop (`for i in range(n)`)**: This loop runs `n` times. Each iteration of this loop represents one complete pass through the list.
2. **Inner Loop (`for j in range(0, n-i-1)`)**: This loop compares adjacent elements and swaps them if they are in the wrong order.
3. **Early Exit Optimization**: An early-exit optimization is not implemented in this version of bubble sort. The function will always perform `n(n-1)/2` comparisons, which is efficient for small lists or when the list is already nearly sorted.
4. **Return Statement**: The sorted list is returned at the end of the function.

### Example Output:
When you run the example usage, it will output:
```

```

This function works by repeatedly swapping adjacent elements until the list is sorted. The early-exit optimization makes it faster for small lists or when the list is already nearly sorted.
