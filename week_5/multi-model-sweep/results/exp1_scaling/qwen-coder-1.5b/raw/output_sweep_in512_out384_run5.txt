Certainly! Below is a Python function that sorts a list of numbers using bubble sort:

```python
def bubble_sort(numbers):
    n = len(numbers)
    
    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n-i-1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater
            # than the next element
            if numbers[j] > numbers[j+1]:
                numbers[j], numbers[j+1] = numbers[j+1], numbers[j]
    
    return numbers
```

### Explanation:
1. **Outer Loop (`for i in range(n)`):** This loop runs `n` times. Each iteration will go through all elements in the array from the beginning to the end.
2. **Inner Loop (`for j in range(0, n-i-1)`):** This loop compares adjacent elements and swaps them if they are in the wrong order. The range `n-i-1` ensures that the last `i` elements are already in place and do not need to be compared.
3. **Early Exit Optimization:** If no swaps are made during an iteration (i.e., the inner loop completes without any swaps), it means the array is already sorted, and the algorithm can exit early.

### Example:
Given the list `[5, 3, 8, 4, 2]`, the function will sort it as follows:
1. First pass:
   - Compare 5 and 3: Swap them (5, 3, 8, 4, 2)
   - Compare 3 and 8: Do nothing (5, 3, 8, 4, 2)
   - Compare 8 and 4: Swap
