Bubble Sort Function
=====================

Here's a Python implementation of the bubble sort algorithm:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using the bubble sort algorithm.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """

    # Create a copy of the input list to avoid modifying it in-place
    numbers_copy = numbers[:]

    # Get the length of the list
    n = len(numbers_copy)

    # Repeat the process until no more swaps are needed
    for i in range(n - 1):
        # Initialize a flag to track if any swaps were made
        swapped = False

        # Iterate over the list, comparing each pair of adjacent elements
        for j in range(n - i - 1):
            # If the current element is greater than the next element, swap them
            if numbers_copy[j] > numbers_copy[j + 1]:
                # Swap the elements
                numbers_copy[j], numbers_copy[j + 1] = numbers_copy[j + 1], numbers_copy[j]
                # Set the flag to True to indicate that a swap was made
                swapped = True

        # If no swaps were made in the last iteration, the list is already sorted
        if not swapped:
            break

    return numbers_copy

# Example usage:
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print("Sorted list:", sorted_numbers)
```

1.  Create a copy of the input list to avoid modifying it in-place.
2.  Repeat the process until no more swaps are needed.
3.  Iterate over the list, comparing each pair
