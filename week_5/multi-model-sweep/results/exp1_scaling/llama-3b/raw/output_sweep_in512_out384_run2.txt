# Bubble Sort Function
## Overview
The following Python function implements the bubble sort algorithm to sort a list of numbers in ascending order.

## Code
```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers in ascending order using the bubble sort algorithm.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """
    # Get the length of the list
    n = len(numbers)

    # Repeat the process until no more swaps are needed
    for i in range(n - 1):
        # Initialize a flag to track if any swaps were made
        swapped = False

        # Iterate through the list from the first element to the second last element
        for j in range(n - i - 1):
            # If the current element is greater than the next element, swap them
            if numbers[j] > numbers[j + 1]:
                # Swap the elements
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
                # Set the flag to True to indicate a swap was made
                swapped = True

        # If no swaps were made in the last pass, the list is sorted
        if not swapped:
            break

    return numbers

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
print("Original List:", numbers)
print("Sorted List:", bubble_sort(numbers))
```

## Explanation
The bubble sort function takes a list of numbers as input and returns the sorted list. It uses the bubble sort algorithm, which repeatedly steps through the list, comparing each pair of adjacent elements and swapping them if they are in the wrong order.
