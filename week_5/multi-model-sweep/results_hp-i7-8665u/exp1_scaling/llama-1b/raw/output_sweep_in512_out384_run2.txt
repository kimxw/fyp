Here is a Python function that implements the bubble sort algorithm:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using the bubble sort algorithm.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: A sorted list of numbers.
    """

    # Get the length of the input list
    n = len(numbers)

    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater
            # than the next element
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
    
    # Return the sorted list
    return numbers

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)

# Print the sorted numbers
print("Sorted numbers:", sorted_numbers)
```

This code defines a function `bubble_sort` that takes a list of numbers as input and returns the sorted list. The function uses two nested loops to compare each pair of adjacent elements and swap them if they are in the wrong order. The outer loop iterates over each element in the list, while the inner loop compares each element with its adjacent element and swaps them if necessary.
