Here's a Python function that implements bubble sort for a list of numbers:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using the bubble sort algorithm.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: A sorted list of numbers.
    """
    # Get the length of the list
    n = len(numbers)

    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater
            # than the next element
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
    
    return numbers

# Example usage:
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print("Sorted numbers:", sorted_numbers)
```

In this function, we start from the first element and move towards the end of the array. In each iteration, we compare each pair of adjacent elements and swap them if they are in the wrong order. We stop the algorithm once a full pass completes with no swaps, meaning the list is already sorted. The function returns the sorted list of numbers.
