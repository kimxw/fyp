Here's a Python function that implements bubble sort to sort a list of numbers:

```python
def bubble_sort(nums):
    """
    Sorts a list of numbers using bubble sort.

    Args:
    nums (list): The list of numbers to be sorted.

    Returns:
    list: The sorted list of numbers.
    """
    n = len(nums)

    # Traverse through all array elements
    for i in range(n):
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater
            # than the next element
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]

    return nums

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print("Sorted numbers:", sorted_numbers)
```

This code defines a function `bubble_sort` that takes a list `nums` as input and returns the sorted list. It implements the bubble sort algorithm by iterating over the list, comparing adjacent elements, and swapping them if they are in the wrong order. The example usage demonstrates how to use the function to sort a list of numbers.
