Here's a Python function that implements bubble sort to sort a list of numbers:
```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using bubble sort.

    Args:
    numbers (list): A list of numbers to be sorted.

    Returns:
    list: The sorted list of numbers.
    """
    n = len(numbers)
    for i in range(n-1):
        # Create a flag that will allow the function to terminate early if there's nothing left to sort
        swapped = False
        # Start looking at each item of the list one by one, comparing it with its adjacent value
        for j in range(n-i-1):
            # If we find an element that is greater than the next element, we can break the loop
            if numbers[j] > numbers[j+1]:
                # Swap values
                numbers[j], numbers[j+1] = numbers[j+1], numbers[j]
                # Set the flag to True so we'll loop again
                swapped = True
        # If no swaps were needed in the inner loop, the list is already sorted, and we can break out of the loop
        if not swapped:
            break
    return numbers

# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
print("Original list:", numbers)
sorted_numbers = bubble_sort(numbers)
print("Sorted list:", sorted_numbers)
```
This implementation has a time complexity of O(n^2) in the worst case, where n is the number of elements in the list, making it less efficient than other sorting algorithms like quicksort or mergesort for large datasets. However, it's still widely used as a teaching tool due to its simple logic and easy-to-understand implementation.

**Important Note:** The early-exit optimization that stops the algorithm once a full pass completes with no swaps is not actually implemented in this Python code. It's a common optimization technique used in many bubble sort implementations, but not a built-in part of the algorithm itself.
