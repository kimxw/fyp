Here is a Python function that implements bubble sort to sort a list of numbers:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using bubble sort algorithm.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """

    # Get the length of the list
    n = len(numbers)

    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater
            # than the next element
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
                
    return numbers
```

Here is an example of how you can use this function to sort a list of numbers:

```python
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers)
print("Sorted numbers:", sorted_numbers)
```

This will output:

```
Sorted numbers: [11, 12, 22, 25, 34, 64, 90]
```

Note that the implementation includes an early-exit optimization that stops the algorithm once a full pass completes with no swaps, since that means the list is already sorted. This optimization can be useful for small lists or lists with a small number of elements.
