**Bubble Sort Implementation in Python**
================================================

Here's a simple implementation of bubble sort in Python:

```python
def bubble_sort(numbers):
    """
    Sorts a list of numbers using bubble sort.

    Args:
        numbers (list): A list of numbers to be sorted.

    Returns:
        list: The sorted list of numbers.
    """

    # Get the length of the input list
    n = len(numbers)

    # Traverse through all array elements
    for i in range(n):
        
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            
            # Traverse the array from 0 to n-i-1
            # Swap if the element found is greater than the next element
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]

    return numbers


# Example usage
numbers = [64, 34, 25, 12, 22, 11, 90]
print("Original list:", numbers)
sorted_numbers = bubble_sort(numbers)
print("Sorted list:", sorted_numbers)
```

**How Bubble Sort Works**
-------------------------

Bubble sort works by repeatedly swapping the adjacent elements if they are in the wrong order.

1.  Start from the first element and compare it with the next element.
2.  If the current element is greater than the next element, swap them.
3.  Repeat steps 1 and 2 until the end of the list is reached.

**Time Complexity**
------------------

The time complexity of bubble sort is O(n^2), making it one of the least efficient sorting algorithms. However, it is simple to implement and can be useful for small lists or educational purposes.

**Space Complexity**
-------------------

The space complexity of bubble sort is O(1), as it only requires a constant amount of extra space to store temporary swaps.
